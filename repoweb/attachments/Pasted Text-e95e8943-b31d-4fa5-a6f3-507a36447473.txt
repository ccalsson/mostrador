1. OBJETIVO GENERAL

Mercado al Toque será una aplicación multitenant que permitirá:

- registrar compradores;
- autenticar usuarios;
- consultar productos publicados por distintos puestos;
- comprar a diferentes puestos;
- generar pedidos independientes por tenant;
- elegir un changarín para retirar y entregar los pedidos;
- realizar seguimiento de los pedidos;
- calificar al changarín;
- construir posteriormente ranking, niveles, puntos e incentivos.

Mostrador continúa siendo el sistema operativo de cada puesto.

Arquitectura objetivo:

Mercado al Toque
        ↓
API Mercado al Toque
        ↓
API / lógica existente de Mostrador
        ↓
Neon / PostgreSQL

NO hacer:

Flutter → Neon

NO crear un segundo sistema de stock.

NO crear un segundo motor de reservas.

NO duplicar productos.

NO duplicar inventario.

NO duplicar la lógica de creación de pedidos si Mostrador ya tiene una implementación existente.

10. TIMESTAMPS OPERATIVOS

14. ELECCIÓN DEL CHANGARÍN

IMPORTANTE:

El comprador elige al changarín.

    ↓

El sistema debe mostrar changarines disponibles.

2. reputación;
3. experiencia;
4. cercanía, si existe información de ubicación.

No bloquear el MVP esperando geolocalización avanzada.
